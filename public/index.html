About BugSafari

BugSafari Database Edition is an Express, MongoDB, Mongoose and Materialize application created for SIT725 Task 4.2P. Bug records are stored persistently in MongoDB, retrieved through a server-side GET endpoint and added through a validated POST endpoint.
